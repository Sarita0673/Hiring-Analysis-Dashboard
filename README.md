# Internship & Fresher Hiring Analysis

## Objective
Analyze genuine, publicly available internship and fresher job listings to identify common roles, skills, technologies, work modes, locations, and stipend disclosure.

## Project structure
- `data/raw/`: source dataset template and original collected data
- `data/cleaned/`: cleaned CSV generated by Python
- `python/analyze_hiring.py`: data cleaning, exploratory analysis, chart generation, and summary output
- `sql/hiring_analysis.sql`: MySQL schema and analysis queries
- `dashboard/`: Power BI dashboard file and generated charts
- `report/`: analysis summary and report template

## Important data rule
The Excel and CSV files initially contain headers only. Add real listings collected from public job portals or official company career pages. Do not treat sample or invented rows as evidence. Record the source URL and collection date for every listing. Do not collect personal or confidential data.

## Setup (Windows / Git Bash)
From the project root:

```bash
python -m venv venv
source venv/Scripts/activate
pip install -r requirements.txt
```

If `python` is not recognized, install Python 3 and enable “Add Python to PATH”, then reopen the terminal.

## Add data
Open `data/raw/internship_hiring_data.xlsx` and add genuine listings below the header row. Keep the column names unchanged. The `Skills` column should use comma-separated skills, for example `Python, SQL, Pandas`. The `Stipend` value can be an amount or `Not Mentioned`. Do not guess missing values.

## Run Python analysis
From the project root:

```bash
python python/analyze_hiring.py
```

The script creates/updates:
- `data/cleaned/cleaned_hiring_data.csv`
- `report/analysis_summary.txt`
- `dashboard/charts/top_roles.png`
- `dashboard/charts/top_skills.png`
- `dashboard/charts/top_technologies.png`
- `dashboard/charts/top_locations.png`

The script intentionally stops if the input dataset has no records.

## Run SQL
1. Open MySQL Workbench and connect to your local MySQL server.
2. Open `sql/hiring_analysis.sql`.
3. Execute the script to create the database/table and analysis queries.
4. Import `data/cleaned/cleaned_hiring_data.csv` into `internship_hiring.job_listings` using the Table Data Import Wizard. Map the columns to the matching table fields.
5. Run the SELECT queries. If importing a date causes errors, ensure `Date_Collected` uses `YYYY-MM-DD` format.

## Power BI
1. Open Power BI Desktop.
2. Select **Get Data → Text/CSV**.
3. Choose `data/cleaned/cleaned_hiring_data.csv`.
4. Create visuals using Role, Skills, Technology, Work_Mode, Location and Stipend.
5. Save the report as `dashboard/Internship_Hiring_Dashboard.pbix`.

A `.pbix` file cannot be generated by this starter package because it must be authored in Power BI Desktop; the `dashboard/` folder is provided for your saved dashboard.

## Suggested visuals
- Cards: total listings, distinct companies, distinct roles
- Bar chart: top roles
- Bar chart: most requested skills (use Python chart for split skills)
- Bar chart: top technologies
- Bar chart: top locations
- Donut chart: work-mode distribution
- Stipend mentioned vs not mentioned

## Final report
Use `report/Project_Report_Template.md`. Replace placeholders with your measured results and discuss data-source limitations and potential bias. Do not make up findings.

For final submission, replace the demo data with verified public job listings and cite each source.
